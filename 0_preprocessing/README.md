
# iLSU-T: preprocessing pipeline

## Introduction 

This is the code repository for pre-processing the videos of the **iLSU-T** dataset, conformed as a part of the PhD thesis on Electrical Engineering of the student Ariel E. Stassi, advised by Gregory Randall (Instituto de Ingeniería Eléctrica, Facultad de Ingeniería, Universidad de la República, Uruguay) and Matías Di Martino (Universidad Católica del Uruguay, Uruguay; and Electrical and Computing Engineering Department, Duke University, USA). 

Original raw data was recorded and provided by Direccion Nacional de Telecomunicaciones (DiNaTel) of Uruguay to Facultad de Ingeniería, Universidad de la Republica, Uruguay.

## Website 
Preprocessed data can be found on our project website: https://iie.fing.edu.uy/proyectos/lsu-ds/iLSU-T

## Data pre-processing 
Each pre-processing script is made into a specific folder per original video. All the generated files will be contained at the same folder.

----------------------------------------------------------------------
### Step 1: RoI video cropping

* <u> Input/s:</u> original video in ```.mxf``` or ```.mp4``` format and a file in ```.txt``` format to specify the region of interest (RoI). In the case of RoI with variable $P$ discrete positions, an additional ```.txt``` file is assumed to define time periods for each RoI. RoI txt file will have as rows as periods, with one row per set of coordinates. Files are assumed to be included at the same directory and had the same root filename.

* <u> Output/s:</u>  a set of $P$ RoI-cropped-deinterlaced videos in ```.mp4```, each with its audio track included.

* <u> Description:</u> in this first step, the plugin ```ffmpeg``` is used to extract a cropped video centered in the uruguayan sign language interpreter. The cropped video is also _deinterlaced_ in the process. 

#### Examples of use:

``` 
python3 step1_ROI_video_cropping.py --folder a_specific_folder
python3 step1_ROI_video_cropping.py --folder a_specific_folder --periods 3
```
---------------------------------------------------------------------------

### Step 2: audio track and automatic captioning 

* <u> Input/s:</u> original video in ```.mxf```.

* <u> Auxiliary output:</u> audio track in ```.wav```. At first, with ```ffmpeg``` is extracted the audio track. 

* <u> Output/s:</u> a set of 5 text files (```.srt```,```.txt```, ```.json```, ```.vtt```, and ```.tsv```) generated by [WhisperX](https://github.com/m-bain/whisperX)) (see [this link](https://github.com/m-bain/whisperX) for API installation.). <u> Note:</u>  for iLSU-T, we only save ```.json``` output file, that contains all the text transcription data.

* <u> Description:</u> in the first step, the plugin ```ffmpeg``` is used to extract the audio track in ```.wav```. In a second step, ```WhisperX``` is used to automatic captioning the audio track. <u>Note:</u> this captioning does not consider if in the video it is or not the signer (please, see pre-processing step 3).


#### Example of use:

``` 
python3 step2_automatic_captioning.py --folder a_specific_folder
```
---------------------------------------------------------------------------

### Step 3: signer detection via face detection

* <u> Input/s:</u> cropped video in ```.mp4``` without audio track.

* <u> Output/s:</u> two outputs in ```.txt``` format: (1) raw face-detection a frame level; (2) a set of periods in seconds units where there is a signer in the ```.mp4``` input scene.

* <u> Description:</u> in the first step, a face detector of ```OpenCV``` is used to detect if the signer is or not in each frame of video. In the second step, frame-wise detections are filtered and formatted to a set of periods of signer presence in seconds units. 

* <u> Dependencies:</u> ```open-cv```, ```numpy```.
#### Example of use:
``` 
python3 step3_signer_detection.py --folder a_specific_folder
```

### Step 4: signer recognition (automatic stage)

Follow the steps of https://github.com/ageitgey/face_recognition/blob/master/examples/face_recognition_knn.py.

For composing the train set, we select with 50 samples per signer in a supervised manner. Then, all the videos were processed by a uniform sampling of one frame per second, and the corresponding signer was classified. A median filter was
applied for post-processing recognition, considering that the minimum time per signer was 30 seconds. 

### Step 5: conform an ELAN project for manual subtitles alignment
* <u> Input/s:</u> subtitle in ```.srt``` obtained from ```WhisperX```.

* <u> Output/s:</u> an ELAN ```.eaf``` file, where it is contained both the video as the subtitle for time and content edition by an LSU specialist. 

* <u> Description:</u> the ```.eaf``` file is generated from the ```.srt``` and ```.mp4``` files, both with the same name and contained at the same folder.

* <u> Dependencies:</u> ```perl``` interpreter, ```sub2eaf.pl``` available at https://github.com/larilampen/eaf-scripts. For opening the ```.eaf``` file, ELAN software is available at https://archive.mpi.nl/tla/elan.

From the Linux terminal, the script ```sub2eaf.pl``` can be run _locally_ by the following command:
``` 
perl sub2eaf.pl subtitle.srt
```
