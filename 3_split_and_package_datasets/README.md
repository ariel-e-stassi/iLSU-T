# iLSU-T: split and package datasets

In order to package dataset for training and testing the selected SOTA methods, please run:
* the script ```split_and_package_features.py``` for split the whole dataset into train, dev and test sets.
* the script ```split_and_package_features_per_source.py``` for split each dataset source (or subset, i.e., Source1, Source 2, and Source 3) into train, dev and test sets.
