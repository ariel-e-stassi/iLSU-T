# iLSU-T: automatic video-clipping and visual features extraction

In this repository section you will find the config files used for running each SOTA method.

Please refer to each folder, and the config files for the whole iLSU-T dataset or the subsets. See "source3" for a subset example. 

Config files are strongly based on its original repostories version, i.e., [SLT](https://github.com/neccam/slt), 
[SCULT](https://github.com/avoskou/Stochastic-Transformer-Networks-with-Linear-Competing-Units-Application-to-end-to-end-SL-Translatio), and [GASLT](https://github.com/YinAoXiong/GASLT).
